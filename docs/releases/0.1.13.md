La cible suivie affiche maintenant ses **PV actuels / PV max**, avec un pourcentage et une barre de vie discrète dans les six modes d’affichage.

Sélectionner une cible dans le filtre affiche ses PV. En « Toutes les cibles », les PV suivent la dernière cible attaquée par le groupe ; les dégâts continuent à inclure toutes les cibles. Les chiffres sont les dernières valeurs reçues du jeu. Une valeur absente affiche « — » ; aucun maximum estimé ou PV déduits des seuls dégâts du groupe n’est présenté comme une lecture réelle.

Les nouveaux rapports JSON et l’historique conservent les PV en fin de combat. Les anciens rapports restent lisibles. Groupe, soins, dégâts reçus, tableaux, courbes et commandes de capture sont conservés.

Télécharger **AionPartyMeter-0.1.13-Windows-x64.zip**, extraire tout puis ouvrir **DEMARRER.exe**. Pour une installation précédente, le lanceur propose la mise à jour. Les dépendances Microsoft sont incluses ; installer Npcap depuis son site officiel si absent. Le ZIP Update est destiné au lanceur ; les sources GPL sont jointes.
